# 🌍 Global PM2.5 Standards Dataset

This repository maintains a **community-validated dataset of national annual PM2.5 standards (µg/m³)**.

## 📂 Dataset

* File: `/data/national_pm25_standards.csv`

---

## ⚠️ Found an outdated or incorrect standard?

Please **DO NOT edit the CSV directly**.

Instead, follow the structured workflow below.

---

## 🛠️ How to Report an Update

1. Go to the **Issues** tab
2. Click **New Issue**
3. Select **"Update National Standard" template**
4. Fill all required fields

---

## 📌 Required Information

You MUST provide:

* Country name
* Current value in dataset
* Suggested updated value
* Year of update
* Official reference (government / legal document preferred)

---

## ✅ Example

Country: India
Old Value: 40 µg/m³
New Value: 35 µg/m³
Year: 2024
Reference: https://example.gov/notification.pdf

---

## 🚨 Important Rules

* No source → Issue will be ignored
* Only official or peer-reviewed references
* Be precise and verifiable

---

## 🔄 Workflow

Issue → Review → Validation → Pull Request → Merge

---

## 🤝 Goal

To build a **globally trusted, continuously updated reference** for air quality policy.
